Batas Pelanggaran

Cara Kerja Sistem Unlock Baru:

  1. Sistem generate 1 kode universal yang berlaku untuk semua siswa
  2. Kode rotasi otomatis tiap X menit (bisa disetting)
  3. Siswa terkunci → minta kode ke proktor/pengawas
  4. Proktor lihat kode di halaman ini → berikan ke siswa
  5. Siswa input kode → ujian terbuka, counter pelanggaran direset
